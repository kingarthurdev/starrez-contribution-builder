Contribution Script Builder

Upload a sheet of residents and conversation notes. This page builds a script you paste into the console of a logged-in StarRez tab. The script creates one Contribution/Interaction per resident. Your sheet stays in this browser tab and isn't uploaded anywhere.

How to run it

  1. Open utaustin.starrezhousing.com and log in. Any StarRez page works, for example the directory.
  2. Press F12 and open the Console tab. You may need to type allow pasting first.
  3. Paste the script and press Enter. It first looks up every UTEID in StarRez. If any aren't found, it stops before creating anything. Otherwise it creates the contributions one at a time, then downloads a results CSV.
  4. If it stops partway, run the same script again. It remembers every student and note it has submitted from this browser, so it continues with the rest and won't create duplicates.
  5. To preview first, choose Dry run above. It looks up each student and prints what it would submit, with each student's name from StarRez, and creates nothing.
